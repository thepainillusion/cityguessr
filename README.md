# CityGuessr

A GeoGuessr-style street-view guessing game. Pick a city (or the whole world),
get dropped on a random street, walk around, then pin where you think you are.
Closer pins score more — 5,000 points max per round.

**Play it here:** https://thepainillusion.github.io/Folder/

## Features

- 10 featured cities plus a World mode with 250 cities worldwide
- Search and play any city on Earth with Street View coverage
- Play areas: city centre, greater region (Sydney, Adelaide), or a custom radius
- 3 / 5 / 10 rounds, optional per-round timer
- Hand-sketched UI

Built with the Google Maps JavaScript API (Street View + Geocoding).
